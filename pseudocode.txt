INITIALIZE: humanScore = 0, computerScore = 0, 

WHILE humanScore < 5 AND computerScore < 5:
    1. LISTEN for button click (Rock, Paper, or Scissors)
    2. GENERATE random choice for Computer
    3. COMPARE choices:
       - IF Human == Computer: "Tie"
       - IF Human wins: humanScore + 1
       - ELSE: computerScore + 1
    4. UPDATE score display on screen

IF humanScore == 5 OR computerScore == 5:
    1. DISPLAY "Winner" message
    2. SHOW "Retry" button
    3. ON CLICK "Retry": Reset scores to 0 and Clear message
